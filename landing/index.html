CLI for GitHub repositories

Measure repository weight before the first clone.

reposizer returns size, stars, and language instantly. Ideal for engineering teams that need fast pre-clone triage and scriptable output.

Read docs View on GitHub

$ npx reposizer torvalds/linux

Repository: torvalds/linux
Size: 4.82 GB
Stars: 190k
Language: C

Zero setup

Use with npx, no global install required.

Automation ready

JSON output supports CI checks and custom scripts.

Works with private repos

Attach GITHUB_TOKEN and keep the same workflow.

Docs

Usage snippets

Install

# recommended
npx reposizer owner/repo

# optional global install
npm install -g reposizer

Core commands

# single repo
reposizer openai/gym

# multiple repos
reposizer openai/gym vercel/next.js torvalds/linux

# detect current git remote
reposizer

Organization scan

reposizer org openai
reposizer org openai --limit 50 --json

JSON output

reposizer openai/gym --json
{
  "repository": "openai/gym",
  "size_mb": 92.15,
  "stars": 31000,
  "language": "Python"
}

Private repositories

export GITHUB_TOKEN=your_token
reposizer your-org/private-repo

Runtime requirement

# Node.js >= 18
node -v
